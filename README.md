# 📦 OmniCatálogo SaaS - MC Distribuição

Plataforma completa de **Catálogo Digital B2B Whitelabel & Pedidos Express via WhatsApp** com gestão multitenant isolada via Supabase, integração de e-mails transacionais via Resend e suporte a subdomínios dinâmicos.

---

## ⚡ Inicialização Rápida

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Testar build de produção
npm run build
```
